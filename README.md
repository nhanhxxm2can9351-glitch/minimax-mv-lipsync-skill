# MiniMax H3 MV 对口型批量生成技能

> 基于 MiniMax H3（海螺）AI 视频生成模型的数字人对口型 MV 批量生产工具包
> 支持：MV 唱歌对口型 / 讲解口播 / 脱口秀 三大内容分支

## ✨ 功能特性

- 🎤 **MV 模式** — 剧情向 / 画面向 双路径，按 SRT 气口自动切段
- 📢 **讲解模式** — 数字人口播、产品介绍、知识科普
- 🎭 **脱口秀模式** — 坐凳固定机位单口喜剧
- 🎬 **电影级运镜** — 推/拉/摇/升/降/环绕/匹配剪辑 8大运镜手法
- 🎨 **角色记忆点系统** — 每人 3 个强记忆点，过目不忘
- ⏱️ **DTMV 时间线** — 自动生成 `dtmv:v1` 格式，直连 ComfyUI 切音频节点

## 🚀 快速开始

### 准备素材
1. 音频文件（MP3/WAV）
2. 音频总时长 T（精确到 0.1 秒）
3. SRT / VTT 字幕（带时间轴）
4. 角色参考图（1-3 张）

### 工作流程
1. **出全片地图** — 按 SRT 气口切段，输出 `dtmv:v1` 时间线
2. **确认切点** — 调整到满意
3. **出逐段提示词** — 每段六段式英文提示词 + 中文分镜
4. **导入 ComfyUI** — DTMV 插件切音频 + H3 模型批量生成
5. **后期合成** — 拼接 + 放大 + 调色

## 📝 dmv:v1 格式

```
0-8.8
8.8-17.0
17.0-25.4
25.4-33.8
33.8-44.7
```

直接粘贴到 ComfyUI DTMV 节点即可自动切音频。
