# 《逍遥仙》前世今生 MV - 人物设计手册 v4.0

> 设计理念：每个角色 3 个强记忆点，前世今生命运呼应
> 核心设定：小和尚 × 狐妖 的前世今生虐恋
> 风格：真人电影质感 | 画幅：16:9

---

## 👨 角色一：释尘（小和尚·古装男主）

### 核心身份
金山寺年轻僧人，修行多年却破了色戒，爱上狐妖。对应歌词"小僧don't leave me alone"。

### ✨ 三大记忆点

| 记忆点 | 描述 | 视觉呈现 |
|---|---|---|
| 1️⃣ **泪滴形戒疤** | 眉心一颗朱砂色戒疤，形状像一滴眼泪（不是普通圆点），是他受戒时天生的异象 | 正面特写最显眼，情绪激动时会微微泛红 |
| 2️⃣ **裂纹旧佛珠** | 脖子上挂一串深色木佛珠，其中一颗有明显的裂纹（用金线缠过），是师父圆寂前留给他的 | 他紧张/念经时会无意识拨动那颗裂珠 |
| 3️⃣ **僧袍补丁** | 灰色僧袍的左袖口和右肘处，各有一块用不同浅色布料缝的补丁（是他自己缝的，针脚有点歪） | 暗示他节俭、动手能力强，也增加人物温度 |

### 补充特征
- **年龄**：约 22 岁
- **发型**：光头（僧人标准），但有一点点青色胡茬
- **眼睛**：清澈的小鹿眼，眼尾微微下垂，看起来无辜又真诚
- **身材**：清瘦挺拔，约 178cm，7.5 头身
- **气质**：外表清冷禁欲，眼神干净，遇到狐妖时会慌乱耳尖红
- **服装**：灰色僧袍（交领右衽），白色中衣领口露出，腰间系深褐色布带，脚穿黑色僧鞋，补丁在左袖口和右肘

### 标志性动作
1. 紧张时手指拨动佛珠（特别是那颗裂的）
2. 害羞时耳尖变红，低头念"阿弥陀佛"
3. 坚定时眉心戒疤微微蹙起

## 👩 角色二：九璃（狐妖·古装女主）

### 核心身份
修行千年的九尾红狐，妖艳惑人却动了真心。对应歌词"你是妖怪"、"妖精休想再勾引我"。

### ✨ 三大记忆点

| 记忆点 | 描述 | 视觉呈现 |
|---|---|---|
| 1️⃣ **异色双瞳** | 左眼是炽烈的琥珀金，右眼是妖娆的胭脂红，笑起来时眼尾上挑，瞳孔会微微变竖瞳 | 近距离对视极具冲击力，特写必给 |
| 2️⃣ **九尾+狐耳** | 情绪激动时身后浮现九条火红色狐尾，平时头发里藏着一对毛茸茸的狐耳（耳尖黑色） | 发丝飘动时偶尔露出，增加灵动妖气 |
| 3️⃣ **赤焰额钿** | 额头正中一个小小的火焰形花钿（赤红色），是她狐族的印记，运功时会发光 | 古装美人标配，辨识度极高 |

### 补充特征
- **年龄**：外表约 20 岁，实际千年
- **发型**：黑色长发如瀑，头顶半挽，其余披散，发间插赤金色发簪
- **唇**：饱满的唇形，涂朱砂色口红，嘴角天生上翘（似笑非笑）
- **身材**：妖娆曲线，约 168cm，7 头身
- **气质**：表面妖艳妩媚，眼神勾人，内心其实单纯执着，爱上了就不顾一切
- **服装**：大红色纱质长裙（层层叠叠），广袖上绣金线火焰纹，领口开得较低，露出锁骨，赤金色腰封，赤脚系红绳脚链

### 标志性动作
1. 诱惑时用指尖轻轻划过对方胸口/下巴
2. 开心时狐耳尖会不自觉地抖一下
3. 伤心时九尾会耷拉下来（但只在没人看见的时候）

## 👨 角色三：林墨（现代男主·小和尚转世）

### 核心身份
年轻建筑师，不信鬼神却总被同一个梦困扰。前世是释尘。

### ✨ 三大记忆点

| 记忆点 | 描述 | 视觉呈现 |
|---|---|---|
| 1️⃣ **半框眼镜+黑绳链** | 复古半框眼镜，镜腿挂着一条细黑绳链（不是金色），链尾有一颗极小的木珠（佛珠碎片的感觉） | 低头工作时眼镜滑鼻尖，推眼镜的动作 |
| 2️⃣ **左手旧佛珠手链** | 左手手腕永远戴着一串旧的深色木佛珠（比正常手链小一圈，像儿童尺寸），其中一颗有裂纹 | 祖传的，他从小戴到大，不知道来历 |
| 3️⃣ **后颈莲花胎记** | 后颈发际线处有一个小小的淡粉色莲花形状胎记，平时被头发遮住，风吹或低头时会露出来 | 呼应前世僧人身份（莲花是佛教象征） |

### 补充特征
- **年龄**：26 岁
- **发型**：清爽短发，有点自然卷，额前碎发
- **胡茬**：偶尔有淡淡的胡茬（加班后）
- **身材**：清瘦，180cm，8 头身
- **气质**：理性、克制、有点社恐，工作时很专注，笑起来有浅浅的梨涡
- **服装**：基础款但质感好——白衬衫（解开两颗扣）、深灰西装外套、黑色直筒西裤、黑色皮鞋，左手佛珠+黑色方形手表

### 标志性动作
1. 思考时无意识拨动左手佛珠
2. 推眼镜（用右手食指指节）
3. 困惑时会摸后颈（刚好摸到莲花胎记的位置）

## 👩 角色四：苏璃（现代女主·狐妖转世）

### 核心身份
独立纹身师 / 插画师，自由不羁，总觉得自己在等一个人。前世是九璃。

### ✨ 三大记忆点

| 记忆点 | 描述 | 视觉呈现 |
|---|---|---|
| 1️⃣ **火焰红挑染** | 黑色长卷发中，藏着几缕火焰红色的挑染（不是全头染，只有几缕），扎起来时看不到，放下来若隐若现 | 风吹或转身时红发丝飘动，呼应前世九尾红狐 |
| 2️⃣ **锁骨狐纹纹身** | 右锁骨下方有一个小小的黑色狐狸脸纹身（线条极简风格），只有凑近才看得见 | 呼应前世狐妖身份，穿低领衣服时若隐若现 |
| 3️⃣ **夸张狐耳耳环** | 永远戴着一对设计感很强的狐耳造型耳环（金属+红色珐琅），走路时轻轻晃动 | 夸张但好看，是她的个人标志 |

### 补充特征
- **年龄**：24 岁
- **发型**：黑色大波浪长卷发，几缕火焰红挑染藏在里面
- **眼睛**：圆圆的杏眼，眼尾微微上挑（狐狸眼的感觉）
- **唇**：饱满唇形，喜欢涂红棕色调口红
- **痣**：左眼下一颗小泪痣
- **身材**：玲珑有致，165cm，7.5 头身
- **气质**：古灵精怪、飒爽不羁、敢爱敢恨，笑起来很有感染力
- **服装**：风格多变——黑色吊带裙+皮衣外套、破洞牛仔裤+露脐装、国风改良裙，手上戴好几个银戒指，脖子上多层项链，脚穿马丁靴或高跟鞋

### 标志性动作
1. 思考时咬下唇
2. 撩头发（把红发丝撩到耳后，刚好露出狐耳耳环）
3. 笑的时候眼睛弯成月牙

## 🎭 前世今生命运对照表

| 前世（古装） | 今生（现代） | 命运呼应 |
|---|---|---|
| 释尘（小和尚） | 林墨（建筑师） | 都是克制/禁欲系，都和"建造/修行"有关 |
| 九璃（狐妖） | 苏璃（纹身师） | 都是自由不羁、敢爱敢恨，都是"艺术家" |
| 泪滴戒疤（眉心） | 黑绳链眼镜（眼前） | 都在面部中心位置有标志性特征 |
| 裂纹佛珠（信物） | 旧佛珠手链（祖传） | 同一串佛珠的延续，穿越千年 |
| 僧袍补丁（朴素） | 基础款衣服（简约） | 审美一致，不喜浮华 |
| 异色双瞳（妖） | 狐狸眼+泪痣（媚） | 眼神都有勾人的特质 |
| 九尾红狐（火） | 火焰红挑染（火） | 红色+火焰元素的传承 |
| 赤焰额钿（印记） | 锁骨狐纹（纹身） | 身上都有特殊标记 |
| 狐耳（本体） | 狐耳耳环（装饰） | 狐耳元素的呼应 |

## 🎨 视觉风格统一

- **古装线色调**：灰+红+金，禁欲与妖艳的强烈对比
- **现代线色调**：黑白灰+红棕，都市感中藏着火焰
- **共通元素**：红色（两人都有红色元素）、佛珠（连接前后世的信物）
- **光影**：都强调侧逆光，勾勒轮廓，增加氛围感
- **比例**：男 178-180cm，女 165-168cm，身高差约 12cm

## 📐 三视图规格

- **画幅**：16:9 横版
- **布局**：左侧 1/3 = 面部特写（胸部以上），右侧 2/3 = 全身三视图（正、侧、后）
- **背景**：纯白色
- **姿态**：自然站立，双臂自然下垂
- **风格**：真人质感，清晰锐利
