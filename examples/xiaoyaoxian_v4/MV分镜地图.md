## 运镜手法总览

| 运镜类型 | 使用场景 | 情绪作用 |
|---|---|---|
| 📷 缓慢前推 | 相遇、对视、暧昧场景 | 凝神聚焦、拉近心理距离 |
| 🔄 环绕 (Orbit) | 双人对手戏、共舞场景 | 仪式感、命运感、二人世界 |
| ⬆️ 升镜 / 降镜 | 出场飞升、结尾大场景 | 升华、开阔、宿命感 |
| 🎯 匹配剪辑 | 古今时空切换 | 命运呼应、前世今生 |
| ⚡ 闪白转场 | 佛珠落地→现代 | 冲击感、时空断裂 |
| 📹 手持晃动 | 冲突场景、诀别 | 真实感、情绪动荡、不安 |
| ⚡ 快切蒙太奇 | 甜蜜回忆、相爱时光 | 节奏感、幸福感、时间流逝 |
| ↔️ 横向跟拍 | 行走、进入场景 | 叙事推进、流动感 |
